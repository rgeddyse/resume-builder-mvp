# Template Sources

The bundled templates are local HTML files designed for this app's replacement-token system.
They are original implementations, with layout ideas checked against permissive/open-source
resume template projects before inclusion.

- Start Bootstrap Resume: https://github.com/startbootstrap/startbootstrap-resume
- Start Bootstrap Personal: https://github.com/startbootstrap/startbootstrap-personal

Both Start Bootstrap repositories are MIT licensed at the time these templates were created.
The app does not copy their full HTML/CSS; it uses local templates tailored to the resume
builder data model so colors, sections, and uploaded resume content render consistently.

The later split-layout templates were shaped from common visual patterns in current resume
template image examples: soft page backgrounds, a white paper canvas, and separate side panels
for contact/skills/education while the main column keeps summary, experience, and projects.
